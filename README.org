#+TITLE: sexp-config
#+STARTUP: content

=sexp-config= reads configuration written as Common Lisp data. A grammar
declares the vocabulary and the bounds a source may use. Anything outside
them signals a machine-readable diagnostic.

#+BEGIN_SRC lisp
(defparameter *grammar*
  (sexp-config:make-source-grammar
   :label "SERVERS.sexp"
   :keywords '(:servers :version :name :command)
   :maximum-depth 16
   :maximum-nodes 512))

(sexp-config:read-source
 "(:servers :version 1 (:name \"local\" :command \"run\"))"
 *grammar*)
;; => (:SERVERS :VERSION 1 (:NAME "local" :COMMAND "run"))
#+END_SRC

* Reading

=read-source= scans the text before the reader sees it, then reads with
=*read-eval*= bound to =nil= inside a throwaway package that is deleted
afterward. The result is structurally validated.
The scan bounds nesting, source nodes and decoded string characters before
allocation. Structural validation counts conses and atoms with an iterative
walk, so flat lists do not consume the control stack. Vector elements count
against the source-node budget.

The scan accepts:

- parentheses, strings, and line comments
- nested =#| |#= block comments when the grammar permits them
- keyword tokens in the grammar's vocabulary
- bare symbols when =:common-lisp-symbols-permitted-p= is true, including
  =nil= and =t=

Leaving both =:keywords= and =:keyword-predicate= unset accepts any keyword.

* Diagnostics

Every rejection signals =sexp-config-error=, carrying:

- a stable =kind= for translation
- the grammar =label=
- a human-readable =message=
- the offending =token= when one identifies the problem
- the =offset= and one-based =line=

Rejections from =validate-tree= carry no position, because structure is
checked after reading. The kinds are =:invalid-syntax=, =:unknown-field=,
=:data-too-deep=, =:data-too-large=, =:invalid-structure=, =:invalid-value=,
=:no-form=, =:multiple-forms=, =:read-error=, and =:invalid-grammar=.

A host that keeps its own diagnostic conditions translates at the boundary:

#+BEGIN_SRC lisp
(handler-case
    (sexp-config:read-source source *grammar*)
  (sexp-config:sexp-config-error (condition)
    (error 'my-configuration-error
           :kind (sexp-config:sexp-config-error-kind condition)
           :message (sexp-config:sexp-config-error-message condition))))
#+END_SRC

=read-source= takes a string. =read-source-file= captures one file's text with
an optional =:maximum-octets= bound, including growth during capture, then
scans and reads that capture. Its rejections carry UTF-8 octet offsets.
File access policy belongs to the caller.

* Data sources

A grammar can also accept data a Lisp printer writes:

- =:octet-vectors-permitted-p= accepts =#( )= vectors holding only integers
  from 0 to 255, read as octet vectors
- =:readable-strings-permitted-p= accepts rank-one =#A= strings with
  =CHARACTER= or =BASE-CHAR= element types and matching dimensions; the
  result is a plain string. The descriptor is bounded independently.
- =:qualified-common-lisp-symbols-permitted-p= accepts the =COMMON-LISP:= and
  =CL:= spellings of external standard symbols, such as =COMMON-LISP:NIL=;
  restrict which ones with =:allowed-atom-predicate=
- =:read-default-float-format= sets the type an unmarked float reads as
  (default =double-float=); match the printer's setting so floats keep their
  type
